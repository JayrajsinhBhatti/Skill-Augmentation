# **Skill Augmentation Portal**

A web-based platform that allows students to showcase their skills, upload participation details, and submit certificates for verification. Once approved by a counselor, points are assigned automatically.

This project was built to streamline skill evaluation and provide a digital alternative to manual tracking of student achievements.

# 🚀 Features

📝 Student Module

Upload participation details and certificates.

View points and approval status.

# 👨‍🏫 Counselor Module

Review submissions.

Approve or reject certificates.

Assign points based on participation.

# 📊 Dashboard

Displays total points earned.

Tracks skill augmentation progress.
